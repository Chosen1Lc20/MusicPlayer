# 音乐播放器 Music Player

一个使用原生 JavaScript（无框架、无构建）开发的网页音乐播放器，支持 **LRC 歌词同步滚动**，导入本地音乐时**自动配齐歌词与封面**。

## 功能特性

- 播放 / 暂停 / 上一首 / 下一首
- 进度条点击与拖动跳转、缓冲进度显示
- 音量调节、静音
- 三种播放模式：列表循环 / 单曲循环 / 随机播放
- **LRC 歌词解析 + 平滑滚动高亮 + 点击歌词跳转**
- 封面旋转动画 + 取自封面的动态模糊背景
- **导入本地音乐：拖入文件夹或一次多选，同名歌词 / 封面自动配对**
- **自动读取内嵌标签：标题、歌手、专辑、封面、内嵌歌词（mp3 / m4a / mp4 / flac / ogg / opus）**
- **没有标签时按「歌手 - 歌名」从文件名推断；中文 GBK 编码的歌词与标签自动识别**
- 键盘快捷键
- 响应式布局（桌面 / 移动端）

## 快速开始

由于浏览器对本地文件 `fetch`（加载 LRC）有跨域限制，建议用本地服务器运行：

```bash
# 方式一：Python（任意一行）
python -m http.server 8000

# 方式二：Node
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

> 也可以直接双击 `index.html` 打开，导入本地文件仍然可用；只是这种 `file://` 方式下，写在 `playlist.js` 里按路径加载的 `.lrc` 会被跨域限制挡住，用本地服务器没这个问题。

播放列表默认是空的，音乐靠导入。

## 导入本地音乐

三种方式，任选其一：

1. **直接拖进页面**：单个文件、多个文件或整个文件夹都可以，出现蓝色遮罩后松手。
2. **「+ 导入文件夹」**：选一个目录，里面的音频、歌词、封面会连同子目录一起导入。
3. **「+ 导入歌曲 / 歌词」**：一次多选，音频、`.lrc`、封面图片可以放在一起选。

导入后标题、歌手、封面、歌词都不需要手写：

- 优先读**内嵌标签**（`.mp3` 的 ID3v2、`.ogg` 的 Vorbis 注释、`.m4a` / `.flac` 的标签）；
- 没有标签就按**文件名推断**：`歌手 - 歌名.mp3`、`01. 歌名.mp3` 都能识别；
- **封面**优先用音频内嵌的图，其次用同名图片，再次用同目录的 `cover.jpg` / `folder.jpg` / `album.jpg` 等；
- **歌词**优先用同名同目录的 `.lrc`，其次用内嵌歌词；编码自动识别 UTF-8 / UTF-8 BOM / UTF-16 / GBK；
- 一次导入很多首会合并重绘，导入上百首也不会卡。

少数情况需要手动处理：歌词与音频**不同名或不在同一目录**时不会自动配对（底部提示条会说明），这时点「+ 当前歌词(.lrc)」给当前播放的曲目单独加载歌词。

## 添加你自己的歌曲

### 方法一：放入 assets 目录并配置列表

1. 把音频放到 `assets/audio/`，封面放到 `assets/cover/`，歌词放到 `assets/lyrics/`。
2. 编辑 `js/playlist.js`：

```js
window.DEFAULT_PLAYLIST = [
  {
    title: "歌曲名",
    artist: "歌手",
    src: "assets/audio/my-song.mp3",
    cover: "assets/cover/my-song.jpg",
    lrc: "assets/lyrics/my-song.lrc",
  },
];
```

### 方法二：页面内导入

见上面的「导入本地音乐」。注意 `playlist.js` 里手写的条目会直接使用你写的标题 / 封面 / 歌词路径，不参与标签解析。

## 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 后退 / 前进 5 秒 |
| ↑ / ↓ | 增大 / 减小音量 |

## 目录结构

```
MusicPlayer/
├── index.html          # 页面结构
├── css/
│   └── style.css       # 样式
├── js/
│   ├── lyrics.js       # LRC 解析器
│   ├── metadata.js     # 标签解析 + 导入配对（内嵌标签 / 文件名推断）
│   ├── playlist.js     # 默认播放列表配置
│   ├── app.js          # 播放器主逻辑
│   └── vendor/         # 第三方库（jsmediatags 3.9.7，MIT）
├── assets/
│   ├── audio/          # 放音频文件
│   ├── cover/          # 放封面图片
│   └── lyrics/         # 放 .lrc 歌词（含示例）
└── README.md
```

## 第三方库

[jsmediatags](https://github.com/aadsm/jsmediatags) 3.9.7（MIT）放在 `js/vendor/`，用 `<script>` 直接引入，用来读 mp3 / m4a / mp4 / flac 的内嵌标签。它不支持 ogg 容器，ogg / opus 的 Vorbis 注释由 `js/metadata.js` 自己解析。

删掉 vendor 目录，播放器仍能正常播放和导入，只是读不到内嵌标签，会回退到文件名推断。

## LRC 歌词格式

```
[ti:标题]
[ar:歌手]
[00:12.00]这是 12 秒时显示的歌词
[01:20.35]这是 1 分 20.35 秒时显示的歌词
```

支持一行多个时间标签（同一句出现在多个时间点）。
